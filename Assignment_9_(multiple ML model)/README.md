# Assignment 9: Customer Fraud Detection with Multiple ML Models

## Project Overview

This project develops a customer fraud-detection workflow from data cleaning through model comparison. Multiple notebooks explore the customer analytics dataset, engineer useful features, prepare encoded data, and test several machine-learning models.

## Tech Stack

- Python 3
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- scikit-learn
- imbalanced-learn
- PyCaret
- Pickle

## Techniques Used

- Date-time conversion and feature cleaning
- Removing irrelevant columns and handling missing values
- One-hot and ordinal encoding
- Feature scaling
- Train-test split
- SMOTE for imbalanced classes
- Decision Tree, Random Forest, Extra Trees, Gradient Boosting, and AdaBoost
- Model comparison and evaluation
- PyCaret-assisted model experimentation
- Exporting processed data and saving models for reuse

## Skills Practiced

- Building an end-to-end fraud-classification workflow
- Feature engineering for customer data
- Working with imbalanced datasets
- Comparing many machine-learning models
- Reproducible preprocessing and model persistence
