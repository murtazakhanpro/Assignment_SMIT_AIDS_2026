# Assignment 6: Customer, Product, and Engagement Analytics

## Project Overview

Although the folder is named NLP, the notebooks primarily implement a multi-table business analytics project. Customer, geography, product, review, journey, and engagement files are combined to understand purchasing behavior and engagement performance.

## Tech Stack

- Python 3
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Excel data with `read_excel()`

## Techniques Used

- Loading multiple Excel datasets
- Cleaning malformed engagement values
- Splitting combined view/click fields
- Joining tables with `merge()`
- Age bucketing with `pd.cut()`
- Grouping and aggregation by country, gender, age, product, and category
- Engagement-rate and conversion analysis
- Bar charts, scatter plots, and correlation heatmaps

## Skills Practiced

- Relational data modeling
- Multi-source data integration
- Customer and product analytics
- Business-question formulation
- Translating analysis into business insights
