# Assignment 7A: Student Performance Regression

## Project Overview

This project predicts student performance from the `student_habits_performance.csv` dataset using a supervised regression workflow.

## Tech Stack

- Python 3
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- scikit-learn

## Techniques Used

- Dataset inspection and exploratory analysis
- Feature and target separation
- Train-test splitting with `train_test_split()`
- Linear Regression
- Actual-versus-predicted visualization
- Regression evaluation with MAE, MSE, RMSE, and R²

## Skills Practiced

- Preparing tabular data for regression
- Understanding continuous target prediction
- Evaluating model quality with multiple metrics
- Interpreting prediction errors
- Visualizing model performance
