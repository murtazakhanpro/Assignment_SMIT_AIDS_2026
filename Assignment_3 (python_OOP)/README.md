# Assignment 3: Python Object-Oriented Programming

## Project Overview

This project introduces Object-Oriented Programming through practical classes such as `Student`, `BankAccount`, `Employee`, `Vehicle`, and `Car`.

## Tech Stack

- Python 3
- Jupyter Notebook

## Techniques Used

- Classes and objects
- Constructors and instance attributes
- Encapsulation with private (`__`) and protected (`_`) attributes
- Getter and setter methods
- Validation inside setters
- Single and multilevel inheritance
- Abstract base classes using `ABC` and `abstractmethod`

## Skills Practiced

- Modeling real-world entities in code
- Protecting and validating object data
- Reusing code through inheritance
- Understanding abstraction and polymorphism
- Designing maintainable Python programs
