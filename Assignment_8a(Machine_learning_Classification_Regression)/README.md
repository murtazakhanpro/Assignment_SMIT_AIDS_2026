# Assignment 8A: California Housing Regression

## Project Overview

This project predicts California housing prices using the `housing.csv` dataset. It compares multiple regression algorithms after cleaning, encoding, scaling, and feature engineering.

## Tech Stack

- Python 3
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- scikit-learn

## Techniques Used

- Missing-value handling with median imputation
- One-hot encoding for `ocean_proximity`
- Feature engineering: rooms per household, bedrooms per room, and population per household
- Train-test split with reproducible `random_state`
- Preprocessing pipelines
- Linear Regression, Decision Tree, and Random Forest regression
- MAE, MSE, RMSE, and R² evaluation
- Actual-versus-predicted plots and feature importance

## Skills Practiced

- Building leakage-aware preprocessing workflows
- Comparing baseline and ensemble models
- Selecting useful features
- Evaluating regression models
- Interpreting feature importance
