# Assignment 4: Movie Dataset Analysis

## Project Overview

This project explores a movie dataset and answers practical questions about ratings, genres, directors, release years, runtimes, votes, and actors.

## Tech Stack

- Python 3
- Jupyter Notebook
- Pandas
- NumPy

## Techniques Used

- CSV loading with `pandas.read_csv()`
- Shape, data types, null-value, and statistical checks
- Filtering rows with conditions
- Value counts and aggregation
- Sorting by ratings and votes
- String cleaning and numeric conversion
- Selecting records by director, genre, and actor

## Skills Practiced

- Exploratory data analysis
- DataFrame indexing and filtering
- Data cleaning and type conversion
- Answering business-style data questions
- Extracting insights from tabular data
