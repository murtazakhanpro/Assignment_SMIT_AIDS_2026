# Assignment 8B: Heart Failure Classification

## Project Overview

This project predicts the `DEATH_EVENT` outcome from clinical heart-failure records. It focuses on binary classification, class imbalance, model comparison, and evaluation.

## Tech Stack

- Python 3
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- scikit-learn
- imbalanced-learn

## Techniques Used

- Dataset profiling and class-distribution analysis
- Correlation heatmap
- StandardScaler feature scaling
- Stratified train-test split
- SMOTE oversampling for the training set
- Logistic Regression, Decision Tree, Random Forest, Gradient Boosting, SVM, and KNN
- Accuracy, precision, recall, F1-score, classification report, and confusion matrix
- GridSearchCV hyperparameter tuning

## Skills Practiced

- Designing a binary classification pipeline
- Handling imbalanced medical data
- Choosing metrics beyond accuracy
- Comparing and tuning models
- Interpreting classification errors
