# Assignment 5: Exploratory Data Analysis

## Project Overview

This assignment applies EDA to loan, hotel booking, and adult-income datasets. The notebooks inspect dataset quality, distributions, categories, missing values, and relationships between variables.

## Tech Stack

- Python 3
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Techniques Used

- Dataset profiling with `info()`, `describe()`, `shape`, and `nunique()`
- Missing-value counting and percentage analysis
- Duplicate detection
- Median and mode imputation
- Category frequency analysis
- Distribution plots, count plots, and box plots
- Outlier detection with the IQR method
- Correlation heatmaps and cross-tabulation

## Skills Practiced

- Asking useful questions during EDA
- Cleaning imperfect real-world data
- Choosing suitable visualizations
- Finding patterns and outliers
- Communicating data observations clearly
