# Assignment 7B: Housing Price Regression

## Project Overview

This project uses the `Housing.csv` dataset to practice predicting a continuous housing-related target with a regression model.

## Tech Stack

- Python 3
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- scikit-learn

## Techniques Used

- CSV loading and dataset inspection
- Exploratory data analysis
- Feature and target preparation
- Train-test split
- Linear Regression
- Actual-versus-predicted comparison
- MAE, MSE, RMSE, and R² evaluation

## Skills Practiced

- Building a complete regression workflow
- Working with housing data
- Measuring model accuracy and error
- Comparing predicted and actual values
- Presenting analytical results visually
