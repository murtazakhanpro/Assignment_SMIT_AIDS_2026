# Assignment 2: Python Loops

## Project Overview

This project practices repetition and iteration in Python through counting, tables, list processing, totals, maximum-value searches, string reversal, and FizzBuzz.

## Tech Stack

- Python 3
- Jupyter Notebook

## Techniques Used

- `for` loops for fixed-range iteration
- `while` loops for condition-based repetition
- `range()` for numeric sequences
- Lists and strings with loop traversal
- Accumulators for sums and totals
- Sentinel-controlled input using `0`
- Conditional branching with FizzBuzz logic

## Skills Practiced

- Designing loop conditions
- Avoiding infinite loops
- Iterating over collections
- Building menu-free console exercises
- Breaking larger problems into steps
