## How to Use

1. Clone the repository:

   ```bash
   git clone https://github.com/<your-username>/SMIT-Assignments-AIDS-2026.git
   cd SMIT-Assignments-AIDS-2026
   ```

2. Open any assignment folder and read its `project_about.md` file first.
3. Launch the relevant notebook with Jupyter:

   ```bash
   jupyter notebook
   ```

4. Keep the notebook's dataset in the same assignment folder when running locally.
