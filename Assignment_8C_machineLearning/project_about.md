# Assignment 8C: Ten-Year CHD Risk Classification

## Project Overview

This project predicts ten-year coronary heart disease risk from the Framingham Heart Study dataset. The target is `TenYearCHD`, where `0` means no risk and `1` means risk.

## Tech Stack

- Python 3
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- scikit-learn
- imbalanced-learn

## Techniques Used

- Median imputation for missing numerical values
- EDA with count plots, histograms, and heatmaps
- StandardScaler feature scaling
- SMOTE class balancing
- Logistic Regression, Decision Tree, and Random Forest classification
- Classification reports and confusion matrices
- GridSearchCV hyperparameter tuning
- Feature-importance analysis

## Skills Practiced

- Preparing health data for machine learning
- Managing missing values and class imbalance
- Comparing classification algorithms
- Tuning model parameters
- Explaining risk-prediction results
