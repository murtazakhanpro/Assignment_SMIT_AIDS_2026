# Coding Gym: Additional Practice

## Project Overview

`Coding_gym` contains extra notebooks for strengthening Python data-analysis and machine-learning skills outside the numbered assignments.

## Tech Stack

- Python 3
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- scikit-learn

## Techniques Used

- Dataset inspection and descriptive statistics
- Missing-value checks
- Data visualization with Seaborn
- Train-test splitting
- Feature scaling and one-hot encoding
- Classification and regression model imports
- Model evaluation with accuracy, F1-score, MSE, R², and confusion matrices

## Skills Practiced

- Reusable machine-learning workflow setup
- Comparing preprocessing strategies
- Exploring datasets interactively
- Building confidence through focused practice
