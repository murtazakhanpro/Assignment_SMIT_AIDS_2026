# Assignment 1: Python Fundamentals

## Project Overview

This project builds the foundation of Python programming through small, practical exercises. It focuses on taking user input, working with strings and numbers, and applying basic decision-making logic.

## Tech Stack

- Python 3
- Jupyter Notebook

## Techniques Used

- String methods: `upper()`, `lower()`, `replace()`, `find()`, `strip()`, and `count()`
- Type casting between `str`, `int`, and `float`
- User input and formatted output
- Arithmetic, comparison, and logical operators
- `if`, `elif`, `else`, and nested conditions

## Skills Practiced

- Writing basic Python syntax
- Handling input and output
- Solving small programming problems
- Applying conditional logic
- Debugging beginner-level code
